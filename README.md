# TurnitoAPI

API for managing general appointments for companies. Will be developed into a bigger project later on.
Make sure to create an appsettings.json file and follow this structure:

{
"Logging": {
"LogLevel": {
"Default": "Information",
"Microsoft.AspNetCore": "Warning"
}
},
"AllowedHosts": "\*",
"ConnectionStrings": {
"DefaultConnection": "Host=localhost;Database=yourdbname;Username=yourusername;Password=yourpass"
}
}
